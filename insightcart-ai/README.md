# InsightCart AI 🛒🧠

An advanced AI-powered E-Commerce Management System with real-time user behavior analysis, personalized recommendations, and a rich admin analytics dashboard.

---

## 🚀 Features

- **User Auth** — Registration, login, JWT sessions
- **Product Catalog** — Full CRUD with categories, images, stock
- **Shopping Cart & Orders** — Cart management, order lifecycle
- **Payment Simulation** — Mock payment gateway with status tracking
- **Behavior Intelligence Engine** — Tracks views, clicks, searches, dwell time
- **Recommendation Engine** — Rule-based + collaborative filtering logic
- **Personalized Homepage** — Dynamic content per user
- **Admin Dashboard** — Analytics, user management, behavioral heatmaps
- **Trending Products** — Based on aggregated user activity

```bash
# 4. Start the server

# 5. Open frontend
# Open frontend/index.html in a browser (or serve via live-server)
```

## 🧠 Behavior Intelligence Engine

The `BehaviorIntelligenceEngine` in `backend/utils/behaviorEngine.js` processes raw events into user behavior profiles:

- **Event Types**: `view`, `click`, `search`, `add_to_cart`, `purchase`, `dwell`
- **Scoring**: Each event type has a weight; scores decay over time
- **Category Affinity**: Tracks which categories a user prefers
- **Trending**: Aggregates all users' activity to surface trending products

Recommendations are generated by:
1. Finding products in high-affinity categories not yet purchased
2. Collaborative filtering — users with similar purchase history
3. Boosting trending products the user hasn't seen
